# 一、总纲

> XiaoG 是一个个人 AI Runtime
> 核心系统。当前阶段优先完成稳定、完整、可长期使用的个人智能环境；未来根据实际需求扩展为网页端、桌面端、移动端等不同形态。

当前核心目标：

不是单纯开发一个聊天网页，而是构建一个可扩展、可控制、属于用户自己的 AI
Runtime。

核心原则：

1.  Core First ------ 核心能力优先，载体后置。
2.  Local First ------ 用户数据优先属于用户。
3.  Capability Driven ------ 能力驱动界面，而不是模型驱动界面。
4.  Secure by Default ------ 敏感信息默认安全存储。
5.  Product Before Expansion ------ 先完成个人长期使用，再扩展外部用户。

# 六、Harness路线

状态：

候选技术探索。

阶段：

0.7之后进行 Deep POC。

不直接集成。

原则：

Harness不能控制XiaoG核心架构。

架构：

XiaoG Core

(API / Policy / Router / Data)

↓

Harness Adapter

↓

Execution Layer

验证：

-   生命周期
-   Tool Policy
-   Event管理
-   Cancellation
-   Provider注入

通过后再决定是否采用。
