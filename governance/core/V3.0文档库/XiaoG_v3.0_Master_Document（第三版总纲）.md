# 第一章 项目定位

## XiaoG是什么

XiaoG不是：

-   ChatGPT Clone
-   DeepSeek套壳
-   单模型聊天前端

XiaoG定位：

> 一个属于用户自己的 Personal AI Runtime。

核心：

模型提供智能。

XiaoG提供：

-   用户数据控制
-   Memory
-   Knowledge
-   Projects
-   Tools
-   Agent
-   Workflow
-   Personalization
