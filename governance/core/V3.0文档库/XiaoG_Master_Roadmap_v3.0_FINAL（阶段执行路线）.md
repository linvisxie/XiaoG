# 一、总目标

XiaoG最终目标：

成为一个：

-   个人拥有
-   用户控制
-   可持续扩展
-   长期可维护

的 Personal AI Runtime。

XiaoG不是：

-   ChatGPT Clone
-   DeepSeek套壳
-   单模型前端

模型只是能力来源。

XiaoG负责：

-   用户数据
-   Memory
-   Knowledge
-   Projects
-   Tools
-   Agent
-   Workflow
-   Personalization
